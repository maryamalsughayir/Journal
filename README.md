# 📔 Journali
**Your thoughts, your story.**

Journali is a simple, minimal journaling app that helps you write down your thoughts, save your favorite memories, and keep your entries organized in one private place.

## ✨ Features
- ✍️ **Add Journals:** Tap the **+** icon to write a new journal with a title and date.
- 📝 **Edit Journals:** Open any journal to update it. If you try to leave without saving, an alert asks whether to discard changes or keep editing.
- 🔖 **Bookmark:** Bookmark your favorite journals to find them quickly.
- 🗂 **Sort & Filter:** Sort your journals by bookmark or by entry date.
- 🔍 **Search:** Find any journal using the search bar.
- 🗑 **Swipe to Delete:** Swipe a journal to delete it, with a confirmation alert to avoid mistakes.
- 🌱 **Empty State:** A friendly screen guides you to start your first journal.

## 🛠 Tech Stack
- Swift
- SwiftUI
- Xcode
- iOS 17+
